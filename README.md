# Piezas web · Innovación Arquitectura Estudio

Piezas interactivas para el sitio de Wix (bloques «Insertar HTML» en modo **Dirección web**).
Se publican con GitHub Pages en `https://innovacionarqydis.github.io/innovacion-piezas-web/`.

| Pieza | Archivo | Altura computadora | Altura celular |
|---|---|---|---|
| Encabezado animado | `encabezado.html` | 120 px | 160 px |
| Dos caminos (botones) | `caminos.html` | 120 px | 280 px |
| Cifras con contador | `cifras.html` | 180 px | 340 px |
| Tarjeta de casas en venta | `casas.html` | 720 px | 1160 px |
| Cómo trabajamos | `proceso.html` | 420 px | 800 px |
| Arma tu proyecto | `arma-tu-proyecto.html` | 1000 px | 2200 px |
| Reporte de obra | `reporte.html` | 470 px | 520 px |
| Preguntas frecuentes (chat) | `preguntas.html` | 520 px | 700 px |

`velo/casas-en-venta.js` es el código de página (Velo) que manda las casas de la base de datos a `casas.html`.
